# Refrigeration Unit

A heat pump for the [Ice Box](Ice_Box.md): the answer to ice that melts. It is an [electrical](Electricity.md) load.

## Crafting

```
P P P
K N K
P P P
```

P is an Iron Plate, K is a Copper Coil and N is a [Condenser](Condenser.md).

## Using it

- Place it against any face of an Ice Box and connect it to a line.
- While it is powered it draws **2 A** and holds the box near freezing. The box needs no ice, and no ice is used up while the unit is running. Ice put in still works if the unit has no power.
- When the power fails the box drifts back to the room's temperature within a couple of seconds, the same as a box with no ice.
- It has no thermostat. It runs whenever it is fed, so switch it with a [Breaker](Breaker.md), a [Relay](Relay.md) or a controller.

## It runs hot

A heat pump moves heat, it does not delete it. While running, the unit itself heats up past scalding (about 115 Tu) over half a minute, so a bare hand on it is burned. Switched off, it cools over a few minutes. It does not warm the blocks around it.
