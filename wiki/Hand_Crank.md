# Hand Crank

The simplest source of [rotation](Rotation.md): it turns as long as you keep turning it.

## Crafting

```
P P
S
```

P is a [Copper Plate](Mechanical_Hammer.md) and S is a [Shaft](Shaft.md).

## Using it

**Hold right-click** on it. Each click keeps it turning for a moment, and holding the button keeps it going. Let go and it stops (and the line coasts down). A shaft can attach to either end.

## How much it can drive

Not much. A hand crank is **too weak to drive a [Mechanical Hammer](Mechanical_Hammer.md)**, or any of the other workshop machines. Hook one up and the network just strains and won't turn. Gearing doesn't help: it changes how hard each turn pushes, not how much load the crank can carry.

It's useful for small loads, like a [Controller](Controller.md), and for learning how shafts behave. For real work you want a [Water Wheel](Water_Wheel.md).
