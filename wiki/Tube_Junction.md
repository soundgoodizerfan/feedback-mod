# Tube Junction

Routes [carriers](Carrier.md) in a [tube](Pneumatic_Tube.md) run by their address color, never by what they hold.

## Crafting

**Tube Junction**:

```
  T
T W T
  T
```

T is Copper Tubing and W is a Wide-Bore Tube.

**Programmed Junction**: Tube Junction + 2 Copper Wire.

## Using it

- **Use a dye on a face** to name the color that leaves that way. The same dye on the same face clears it.
- **Sneak with an empty hand** to clear every face.
- A carrier with no matching color leaves by the first open face.

## Programmed Junction

A junction that returns what it cannot place. Dye a face to name its color, and **click a face with an empty hand** to make it the return line. A carrier with no matching color goes to the return line, and waits while that line is full rather than going astray.
