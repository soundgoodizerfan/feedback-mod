# Reflow Oven

The capital route to a joint: a chamber that holds up to four pasted boards at once, no attention needed.

## Crafting

```
P P P
C _ C
B B B
```

P is a Wrought Iron Plate, C is Ceramic and B is Bricks.

## Using it

Set it on a [Firebox](Firebox.md). **Right-click with a pasted [Trace Board](Trace_Board.md)** to load one. **Right-click with an empty hand** to take the whole batch out; each board's joints are set at that moment from the hottest it got and how long it sat above the solder's melting point ([Solder](Solder.md)).

It is a thermal body like a [Crucible](Crucible.md): a [Thermometer](Thermometer.md) reads it, it cools into the room, and a hot oven burns a bare hand. Each board adds weight, so a full cold batch pulls the chamber down, and a board is always a little behind the oven's heat.

## Overrun

A finished [circuit](Basic_Electronic_Circuit.md) can be baked again; past its traces' limit it lifts and goes dead.

Leave the batch in a hot oven and it cooks. Past the solder's window the joints go cold. Past what the traces stand they lift and the board comes back as bare substrate. The solder is gone either way. It never refuses to run. Leaded solder gives off poison fumes while it is molten.
