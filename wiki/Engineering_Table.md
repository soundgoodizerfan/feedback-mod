# Engineering Table

A second drawing table, for machines and what they are built from: engines, gearboxes, propellers, motors, cells, belts and [suit modules](Exosuit.md#upgrade-modules). It works exactly like the [Blueprint Table](Blueprint_Table.md#using-it), with the same board, figures, pins and Print button.

## Crafting

```
B I
I I
```

B is a Blueprint Table and I is an Iron Ingot.

## Using it

The type row and the full list show only the types this table draws. The [Blueprint Table](Blueprint_Table.md) draws everything else, and each table refuses the other's types with a message naming the right table.

A suit module is drawn here only from a plan sheet of its kind in the paper slot; see [Learning a module](Exosuit.md#learning-a-module).

See also [Engine](Engine.md), [Transmission](Transmission.md), [Propeller](Propeller.md) and [Conveyor Belt](Conveyor_Belt.md) for what each type draws.
