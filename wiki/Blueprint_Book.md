# Blueprint Book

Carries up to sixteen blueprints, the way a bundle carries items. The [Engineering Table](Engineering_Table.md) reads every sheet inside the book from its blueprint slot.

## Crafting

Leather + 3 Paper + String (shapeless).

## Using it

- Click a blueprint onto the book to put it in.
- Click the book on an empty slot to take a sheet out.

Only blueprints go in. The sheets in a book count exactly as if each lay in the blueprint slot on its own; see [Learning a module](Exosuit.md#learning-a-module).
