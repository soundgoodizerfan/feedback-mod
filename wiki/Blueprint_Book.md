# Blueprint Book

Carries plan sheets, the way a bundle carries items. A bench that wants a plan reads every sheet inside the book from its plan slot.

## Crafting

Leather + 3 Paper + String (shapeless).

## Using it

- Click a plan sheet onto the book to put it in.
- Click the book on an empty slot to take a sheet out.

Only plan sheets go in. The sheets in a book count exactly as if each lay in the plan slot on its own; see [Learning a module](Exosuit.md#learning-a-module).
